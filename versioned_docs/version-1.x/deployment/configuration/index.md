# Configuration

This section provides a complete reference for configuring all OpenCDMP services. Each service is configured through environment variables, typically stored in `.env` files used by Docker Compose.

:::tip New to OpenCDMP?
Start with the [Deployment Guide](/deployment/install/) to get a working installation first. Return here when you need to customise individual services beyond the default configuration.
:::
