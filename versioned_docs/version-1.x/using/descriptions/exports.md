# Exports

You can export the structure of a description in the following formats:
- **PDF**
- **DOCX**
- **XML**

:::info
- File formats `PDF`, `DOCX` exports are done by [file transformer services](/versioned_docs/version-1.x/optional-services/file-transformers/index.md)
- You can use the export feature if current description status has this action. More details can be found [here](administering/system-configuration/description-statuses.md)
:::

![Export a description](/images-1.x/descriptions/exports/export-description.png)
*Export a description*

:::tip
- `Export` the button can be used both internally in the form and externally in [`My Descriptions`](using/descriptions/my-descriptions.md) and [`Description Overview`](using/descriptions/description-overview.md)

:::
