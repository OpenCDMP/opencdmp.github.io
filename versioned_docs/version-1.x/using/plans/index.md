# Plans

A **Plan** is the primary entity in OpenCDMP, representing a complete Output Management Plan (OMP) such as a Data Management Plan (DMP) or Software Management Plan (SMP).

Every Plan is built on a **Blueprint**, which defines its sections and structure. Within those sections, users add **Descriptions** to document specific research outputs (datasets, software, publications, etc.). Plans support collaborative editing, versioning, review workflows, export in multiple formats, and deposit to external repositories for DOI assignment.
