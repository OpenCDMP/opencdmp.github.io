# Plans

A **Plan** is the primary entity in OpenCDMP, representing a complete Output Management Plan (OMP) such as a Data Management Plan (DMP) or Software Management Plan (SMP).

Every Plan is built on a **Blueprint**, which defines its sections and structure. Within those sections, users add **Assets** to document specific research outputs (datasets, software, publications, etc.). Plans support collaborative editing, versioning with version comparison, review workflows, download in multiple formats, and publishing to external repositories for DOI assignment.

Use the guides below to learn how to create and manage your plans.
