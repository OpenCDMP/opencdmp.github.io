# Assets

An **Asset** is a detailed entry within a [Plan](/docs/using/plans/index.md) that documents a specific research input or output, for example a dataset, a piece of software, a publication, or any other project output.

Each Asset is based on an **Asset Template**, which defines the questions and fields to fill in. Assets are added inside a Plan's sections (as configured by the Blueprint), and a Plan usually contains several Assets, one for each distinct output.

Use the guides below to learn how to create and manage your assets.
